# Homepage Images

Drop homepage image files into this folder using the exact filenames below.
If an image is missing, the homepage automatically falls back to a styled
CSS gradient placeholder — nothing breaks.

## Required / recommended files

| Filename | Where it's used | Suggested subject | Recommended size |
|---|---|---|---|
| `hero.jpg` | Main hero background at top of the homepage | Dark, moody shot of a car (night street, headlights, etc.) | 2400 x 1400, JPEG |
| `showcase.jpg` | Full-width "From daily drivers to dream machines" visual break | Luxury / sports car (Lamborghini-style) | 2400 x 900, JPEG |
| `showroom.jpg` | "Your search for rentals STOPS here!" section | Car showroom or row of vehicles | 1200 x 900, JPEG |
| `drive.jpg` | "Drive with UFS" section visual | Person driving or keys in ignition | 1200 x 900, JPEG |
| `host.jpg` | "Host with UFS" section visual | Owner handing over keys or hosting scene | 1200 x 900, JPEG |
| `blog-1.jpg` | First blog preview card | Road trip / driving lifestyle | 800 x 500, JPEG |
| `blog-2.jpg` | Second blog preview card | Money / earnings / calculator | 800 x 500, JPEG |
| `blog-3.jpg` | Third blog preview card | Insurance / safety / documents | 800 x 500, JPEG |

## Tips

- Keep files under ~300 KB each for fast page loads. Use an online JPEG compressor if needed.
- Any filename you use must match exactly (case-sensitive on most servers).
- To remove an image later, just delete the file — the CSS placeholder will return automatically.
- For best visual balance, hero and showcase images should have darker or high-contrast subjects so the white text on top stays legible.
